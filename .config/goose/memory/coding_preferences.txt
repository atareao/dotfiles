# configuracion desarrollo preferencias fish podman quadlets just
## Configuración completa de goose para Lorenzo

### 🐟 Shell
- Fish 4.7.1 (NO Bash)
- GOOSE_SHELL: fish en config.yaml
- Config: ~/.config/fish/config.fish

### 🐳 Contenedores
- Podman 5.8.3 rootless (sin sudo)
- alias docker=podman en config.fish
- **NO usar docker-compose ni podman-compose**
- **Único estándar: Quadlets** (~/.config/containers/systemd/)
  - Archivos separados: .container, .volume, .network
  - Health checks obligatorios
  - Dependencias con After + Requires
  - systemd --user para gestión

### 📋 Automatización de proyectos
- **Herramienta principal: just** con .justfile por proyecto
- just 1.55.1 instalado en /usr/bin/just
- Cada proyecto tiene su propio .justfile con recetas específicas
- Usar just para build, test, deploy, sync, etc.
- Preferir just recipes sobre comandos ad-hoc
