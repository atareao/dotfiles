# gitflow pre-commit ci
Pre-commit checklist (GIT_FLOW.md):
Siempre ejecutar en este orden antes de cualquier commit:
1. cargo fmt --manifest-path backend/Cargo.toml -- --check
2. cargo clippy --manifest-path backend/Cargo.toml -- -D warnings
No commitear si cualquiera falla. Esto evita CI failures en main/development.
